**Hero**
- H1: "Healthcare EHR Analytics Solutions"
- Sub: "Rather than limiting you to a few basic metrics, our structured data approach gives you comprehensive analytical tools with the flexibility to reveal valuable answers."

**Three Report Category Labels**
1. Administrative Analytics
   - Find specific patients for follow-up
   - Analyze visit volume trends and code distribution
   - Identify patients lost to follow-up for high-risk diagnoses
2. Provider Analytics
   - Analyze E&M distribution and outbound referral patterns
   - Track and benchmark outcomes
   - See how referring providers affect the bottom line
3. Financial Analytics
   - Spot reimbursement trends before they affect cash flow
   - View charges, payments, and adjustments by payer group
   - Track month-over-month changes in A/R

**Four Healthcare Analytics Types (FAQ content)**
1. **Descriptive**: "What happened?" — e.g., monthly visit volume
2. **Diagnostic**: "Why did it happen?" — e.g., increased denial rates
3. **Predictive**: "What is likely to happen?" — e.g., no-show rates
4. **Prescriptive**: "What should we do?" — e.g., treatment path optimization
